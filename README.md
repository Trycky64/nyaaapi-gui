# NyaaAPI GUI

A desktop interface for the unofficial Nyaa-API, powered exclusively by the
[`nyaaapi-client`](https://github.com/Trycky64/nyaaapi-client) Python library.

## Development

Requires Python 3.11 or newer. Install the project with `python -m pip install -e ".[dev]"`
and launch it with `python -m nyaaapi_gui`.
